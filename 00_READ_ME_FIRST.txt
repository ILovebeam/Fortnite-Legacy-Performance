==============================================================
   FORTNITE - LEGACY PERFORMANCE MODE RESTORE
==============================================================

  what this is
  ------------
  the pre-2023 dx11 performance mode renderer, pulled from a
  chapter 2 launcher build, patched to work with the current
  epic launcher.

  doesn't replace anything. same login, same account, same
  install. it just swaps the renderer path back on at launch.

  how to run it
  -------------
  1. close the epic games launcher if it's open
  2. double-click EpicGamesLauncher.exe
  3. windows will pop a "smart screen" warning - that's
     normal for unsigned exes. click:
         more info  ->  run anyway
  4. the epic launcher reopens, log in if it asks
  5. launch fortnite, go into creative, check your fps
